Interaction notes

  • The gold guidance line is the only LLM-authored text on screen — hidden prompt, visible as plain help. No bubbles, no transcript.
  • Question order adapts to the detected category (jacket → shoulders first; trousers → waist/inseam). Without an LLM provider, a deterministic per-category list renders instead — the flow never dead-ends.
  • Inputs are Data-typeface (monospace): the eye reads "real number," per DESIGN_SYSTEM §2.
  • I don't have this number records an honest null; that region later shows "not measurable," exactly like Phase 5's chest/waist handling.
  • Skeleton state while the assistant picks the next card — no fake progress animation (§4 rule).
  • All targets ≥ 44pt; Reduced Motion collapses the card transitions to immediate swaps.

Design decisions baked into these screens

D1

Conversational intelligence, not chat UI

The assistant decides what to ask next and writes one guidance line. The surface stays structured input — fields, diagrams, progress. No thread, no bubbles: Atelier is a visual app (AGENTS.md product identity).

D2

The LLM asks and explains — never computes

Fit comes from the deterministic size engine (PRODUCT_SPEC §8, Phase 5 lineage). The LLM may not output measurements, scores, or confidence values — that boundary is constitutional (AGENTS.md rule 5).

D3

Link reading is read-only extraction

Only explicitly printed chart values surface, with provenance + freshness. No chart → NO_SIZE_CHART (§12), stated plainly. Estimation is a prohibited act, not an edge case.

D4

Trends from an indexed source

No per-request live web search. The slot renders source data with attribution, or renders honestly inactive until the source and its schema are defined.

D5

Every state drawn, including the empty ones

Not-found, not-measured, and not-connected are designed frames, not afterthoughts. Glass and motion never mask waiting (§3, §4).

D6

Tokens as specified

Ink canvas, Graphite glass at ~66% over 20px blur with 1px Fog hairlines, Spotlight Gold reserved for CTA + match ring + active progress, Data typeface on every number, ≥44pt targets.

Open questions before any implementation

Gemini requires an externally issued key — conflicts with the standing keyless directive

Recorded 2026-08-17: no phase may depend on externally issued keys. The flow above is therefore designed provider-agnostic — with no LLM provider configured, gathering falls back to the deterministic per-category question list (works, just non-adaptive), and link-reading stays unavailable with an honest state. Gemini can slot in later if a key is ever provided on your own initiative; the UI doesn't change.

Trend source contract

Source, schema, and freshness cadence are undefined (Phase 3 deferred Trend factor). Screen 3's connected state assumes at minimum: a headline signal, attribution name, and refresh timestamp.

Sample content boundary

Everything on this page is illustrative. Any real build reverts to the doctrine: real analyses, real charts, honest nulls — the mockup's job is layout, hierarchy, and voice only.
